# Пантеон — сайт фитнес-клуба

Одностраничный адаптивный сайт фитнес-клуба: абонементы и цены, тренеры, галерея, контакты с картой и форма заявки на консультацию.

**Сайт:** [alexanderkoldin.github.io/PanteonFitness](https://alexanderkoldin.github.io/PanteonFitness/)

**Стек:** HTML5 · SCSS · JavaScript · Gulp · Swiper · PHPMailer

## Что сделано

- Адаптивная вёрстка на Flexbox и Grid, от телефона до десктопа.
- Бургер-меню, плавная прокрутка к разделам, всплывающие окна.
- Слайдер галереи на Swiper.
- Форма заявки с маской телефона (Inputmask) и валидацией (JustValidate). Заявка отправляется на почту небольшим PHP-скриптом на PHPMailer.
- Стили написаны на SCSS и собраны Gulp.

## Структура

```
index.html     разметка страницы
css/           собранные стили
JS/            скрипты: меню, слайдер, попапы, форма, карта
mail.php       отправка заявки на почту
images/        изображения
```
